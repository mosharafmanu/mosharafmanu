# Mosharaf Hossain

Senior web developer — **WordPress, WooCommerce & Shopify**. 9+ years building, fixing and maintaining websites for agencies and businesses in the UK, US, Europe, Canada, Australia and the UAE.

Most of my work starts with someone else's code: a site that broke after an update, a store that got slower one plugin at a time, a Figma design an agency needs built properly. I read what's there, find the real cause, and change only what needs changing.

### What I do

- **Custom WordPress** — hand-written themes and plugins, ACF Pro Flexible Content, Gutenberg blocks (`block.json`, dynamic rendering), Elementor Pro widgets
- **WooCommerce** — custom stores, cart and checkout customisation, payment and third-party integrations, debugging live stores
- **Shopify** — Liquid themes, custom sections, metafields, Shopify CLI on draft themes
- **Bug fixing & performance** — critical errors, plugin conflicts, Core Web Vitals, TTFB, slow queries
- **Agency support** — white-label development and long-term maintenance across client sites

### How I work

`reproduce → investigate → root cause → fix → test → regression check`

Staging first. WordPress APIs and hooks, never core or plugin-file edits. Honest estimates based on real scope.
